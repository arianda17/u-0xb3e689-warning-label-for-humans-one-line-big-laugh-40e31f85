# Warning Label for Humans: One Line, Big Laugh

A single-line safety warning label that should come printed on every human being.

## Winning entry

WARNING: This human believes it can fix anything with duct tape, blind confidence, and a YouTube tutorial it has not watched yet.

## Run

```bash
python3 main.py
```

The program writes the label to `/output/entry.txt` and prints it to stdout.
